# 阅读分享链接

把当前文件或文件夹生成**只读阅读站点**的短链接，并在浏览器里直接打开。

它不自己渲染网页，而是和你本机运行的 [ShareSite](../README.md) 服务配合：扩展负责「定位文件 → 申请短 id」，站点负责渲染 Markdown、图片和文档。

## 命令

| 命令 | 位置 | 作用 |
| --- | --- | --- |
| 分享：在浏览器中打开 | 编辑器标题栏 / 资源管理器右键 | 生成链接并打开浏览器 |
| 分享：复制阅读链接 | 标题栏 / 右键 | 复制当前文件的链接 |
| 分享：复制所在目录的浏览链接 | 右键 | 复制所在目录的链接 |
| 分享：复制阅读站点首页链接 | 命令面板 | 复制首页链接 |

## 前提

1. 本机已按 [ShareSite 文档](../README.md) 配好并启动服务；
2. 在设置里填 `qgzShare.configPath`，指向那份 `config.json`（留空时依次尝试环境变量 `QGZ_SHARE_CONFIG`、`~/.qgz-share/config.json`）。

## 设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `qgzShare.configPath` | 空 | 配置文件路径 |
| `qgzShare.baseUrl` | 空 | 覆盖配置里的公网地址 |
| `qgzShare.shortLinks` | `true` | 优先使用 8 位短链接 |

## 行为细节

- 只有 `config.json` 里 `enabled: true` 的目录才能生成链接，其余会明确提示；
- 短链接需要本机服务在跑：扩展会请求 `http://127.0.0.1:<port>/api/link`，1.2 秒超时；
- 请求失败时**不会报错**，而是回退成 `/view?p=...` 长链接；
- 支持自定义编辑器（webview）与差异编辑器：前者从活动标签页取 URI，后者取 `modified` 一侧；
- 支持 `vscode-remote` 路径。
